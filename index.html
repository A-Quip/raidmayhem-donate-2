How to donate

Put a marker in your tip message to choose what to send. The amount sets how many (count = amount divided by the price), up to 256 mobs or 512 items per tip. Only the first marker in a message counts, so it's one effect per tip; effects fire once no matter the amount. Prices are set by the streamer and may change.

Examples:
MOB:Enderman sends endermen
ITEM:Diamond sends diamonds (multi-word names use an underscore, like ITEM:golden_apple)
EFFECT:Heal heals all runners
Add IGN:YourName to control the mob you send.
